# Fontes

Arquivos variáveis (woff2, subconjuntos latin e latin-ext, que cobrem o português):

- **Figtree** — © The Figtree Project Authors, SIL Open Font License 1.1.
- **Bricolage Grotesque** — © The Bricolage Grotesque Project Authors, SIL Open Font License 1.1.

Copiados de `@fontsource-variable/figtree@5.3.0` e `@fontsource-variable/bricolage-grotesque@5.3.0`.
As fontes são servidas pela própria aplicação (via `next/font/local`): nenhuma requisição a
servidores de terceiros é feita para carregá-las.
